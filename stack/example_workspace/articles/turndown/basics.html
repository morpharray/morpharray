The Basics of Using Turndown

Turndown is a simple yet powerful JavaScript library that converts HTML into Markdown. It is especially popular in browser extensions, note-taking tools, and AI-powered workflows because it is lightweight and highly customizable.

Installation

You can install Turndown using npm or include it directly via CDN.

npm install turndown

Basic Usage

Here’s the simplest way to use Turndown:

import TurndownService from 'turndown';

const turndownService = new TurndownService();

const html = '<h1>Hello World</h1><p>This is a test.</p>';

const markdown = turndownService.turndown(html);

console.log(markdown);

Common Configuration Options

Turndown allows you to customize the output with several options:

Option Default Value Description
headingStyle setext Use atx (# style) or setext (underlined)
codeBlockStyle indented Use fenced for triple backticks
bulletListMarker * Choose between *, -, or +
strongDelimiter ** Use ** or __ for bold text

Enabling Table Support (Most Important Step)

By default, Turndown does not convert HTML tables to Markdown tables. You must add the GFM plugin:

import TurndownService from 'turndown';
import * as turndownPluginGfm from 'turndown-plugin-gfm';

const turndownService = new TurndownService({
    headingStyle: 'atx',
    codeBlockStyle: 'fenced',
    bulletListMarker: '-'
});

// Enable GitHub Flavored Markdown features (including tables)
turndownService.use(turndownPluginGfm.gfm);

// Or enable only tables:
turndownService.use(turndownPluginGfm.tables);

Quick Reference: Most Used Options

  • headingStyle: 'atx' → Produces clean # ## ### headings
  • codeBlockStyle: 'fenced' → Uses ``` for code blocks
  • bulletListMarker: '-' → Uses hyphens for bullet lists
  • strongDelimiter: '**' → Uses ** for bold text

Pro tip: Always test your converter with real content that includes tables, nested lists, and inline formatting before releasing it to users.

Once you have Turndown configured with the GFM plugin, it becomes a reliable tool for turning HTML articles into clean, readable Markdown — exactly what tools like the MorphArray Stack extension need.
