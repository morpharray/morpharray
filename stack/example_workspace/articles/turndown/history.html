History and Challenges of Turndown: Converting HTML to Markdown

Turndown is one of the most popular JavaScript libraries for converting HTML into clean Markdown. While it is lightweight and highly configurable, it also highlights some of the classic challenges developers face when building HTML-to-Markdown converters.

Origins of Turndown

Turndown began as a project called to-markdown, created by Dom Christie. It was later renamed and moved to the mixmark-io organization on GitHub, where it continues to be actively maintained.

Its main appeal lies in its simplicity, speed, and extensibility through plugins.

Common Conversion Challenges

Many HTML elements convert smoothly, but others require extra configuration. One of the most frequent pain points is table handling.

Table Support in Turndown

By default, plain Turndown does not convert HTML tables into Markdown tables. It simply extracts the text content, which often results in flattened, hard-to-read output.

Here is a comparison of Turndown versions and their capabilities:

Version Release Period Major Improvement Table Support
to-markdown (early) 2015–2016 Basic HTML to Markdown None (flattens tables)
Turndown 5.x / 6.x 2018–2022 Plugin architecture Requires GFM plugin
Turndown 7.x 2023–present Better stability and maintenance Requires GFM plugin

Other Elements to Test

The true quality of an HTML-to-Markdown converter shows itself when dealing with mixed content — tables combined with formatting, nested lists, and code blocks.

  • Main conversion goals
    • Preserve semantic structure
    • Maintain readability in Markdown
    • Handle inline formatting correctly
  • Advanced features worth testing
    • Tables with complex content
    • Nested lists
    • Code blocks with language specification
